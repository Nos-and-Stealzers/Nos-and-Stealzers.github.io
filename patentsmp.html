Our Java survival server: recipe patents, a player economy, ranks, auctions and custom powers. Join it with the normal Java Edition client.

Server address

How to join

  1. Open Minecraft Java Edition (any launcher) on version 1.8.8 up to the latest.
  2. Go to Multiplayer, then Add Server, and paste the address above.
  3. Join. You land in a locked lobby until you sign in.
  4. First time: type /register <password> <password>. Every visit after that: /login <password>.

Good to know

  • Cracked launchers are allowed. The password protects your name, so pick one you do not use elsewhere.
  • 1.8 clients cannot see the custom models and some effects, and they use the newer combat timing. Use a recent version for the full experience.
  • The server is hosted on a home PC, so it is sometimes offline. If you cannot connect, try again later.
  • Browser Eaglercraft is not supported. It was removed from the hub after a takedown.
