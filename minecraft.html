PatentSMP server

In your browser

  1. Open 1.12.2 above (any browser version works).
  2. Click Multiplayer. PatentSMP is already in the list.
  3. Join, then type /register <password> <password> the first time and /login <password> after that.

Java Edition (launcher)

Any version from 1.8.8 to the latest. Add this address under Multiplayer:

patentsmp.arcadecampushub.online

Launcher players skip the password, except admins and names that already have one. Own the real Minecraft account? Type /premium once to lock your name to it and never type a password again. Full guide on the server page.
